# 人工智能使用情况说明

## 一、使用目的

本项目在研究、编程调试、数据核对和文字整理过程中使用了人工智能工具，主要目的是提高资料整理和程序检查效率，辅助发现可能存在的逻辑错误。人工智能工具未替代参赛队员进行问题分析、模型构建、参数选择、结果判断和论文撰写。

## 二、具体使用情况

1. **程序检查与调试**

	对 MATLAB 和 Python 程序的运行流程、变量含义、数据读取方式、线性规划约束以及储能状态更新过程进行辅助检查；根据程序报错或运行结果分析可能的路径、维度和单位问题。

2. **数据整理与结果核对**

	辅助编写和检查数据导出程序，将 Q2 的结果整理为 Origin 可读取的 CSV 文件。对指定日期的逐时段购电量、全年紧急购电矩阵、年度费用和紧急购电天数进行交叉核对。最终数据以项目中的 Excel、NPZ 和 JSON 文件为准，并由参赛队员实际运行程序确认。

3. **模型流程审阅**

	对 Q2 的“预测—日前优化—实时调度—储能状态更新—滚动到下一天”流程进行逻辑审阅，辅助检查预测数据与实际数据的使用时机、储能约束、紧急购电条件及单位换算是否表述准确。

4. **论文和支撑材料整理**

	辅助检查文字表述、章节结构、变量说明和图表说明，使模型假设、计算流程和结果解释更加清晰。论文中的具体观点、公式、参数和结论均由参赛队员结合题目要求和程序结果确定。

## 三、人工复核与责任说明

人工智能生成的建议和代码只作为参考，不直接作为最终结论。参赛队员对以下内容进行了人工确认：

- 原始附件、Excel 文件和程序输出之间的数据对应关系；
- 预测模型、目标函数、约束条件及实时调度规则；
- 充放电效率、时间步长、功率和能量等单位换算；
- 程序是否能够正常运行，以及结果是否满足储能上下限和能量守恒条件；
- 论文中的表格、图形、数值结果和结论是否与最终程序输出一致。

本项目的模型设计、程序组织、结果分析和最终论文内容由参赛队员完成并负责。人工智能工具没有替代参赛队员独立思考，也没有未经核验地直接采用其输出结果。

## 四、使用结论

人工智能在本项目中主要承担辅助检索、代码检查、数据核对和文字润色等工作。
