# 人工智能使用情况说明

本文件依据《全国大学生数学建模竞赛人工智能工具使用规定（2026年试行）》第4条编写，用于说明本参赛队在竞赛过程中使用人工智能工具的具体情况。

## 一、所用人工智能工具

- **工具名称**：OpenAI Codex（桌面客户端，AI编程与写作辅助智能体）。
- **版本或型号**：Codex，底层模型为 DeeepSeek v4.1 Flash 和 kimi-k3
- **提供方与访问方式**：OpenAI 提供，通过本地桌面客户端联网调用。
- **主要使用时间**：2026年9月10日至2026年9月13日。

## 二、使用目的和具体环节

本参赛队将人工智能工具用于资料整理、程序检查、数据核对、图表制作指导、论文写作辅助和排版检查等辅助环节。人工智能工具未替代参赛队员进行问题分析、模型构建、参数选择、结果判断和最终论文撰写，具体使用情况如下：

1. **结果口径核验与数据整理**

	读取自编程序输出的 `summary2.json`、`summary3.json`、结果表格等汇总文件，辅助核对计划购电量、计划购电费用、紧急购电量、年度费用和紧急购电天数等指标是否符合题目要求的统计口径。报告期按照2025年2月1日至12月31日计算，共334天。辅助编写和检查数据导出程序，将问题二结果整理为 Origin 可读取的 CSV 文件，并对指定日期逐时段购电量、全年紧急购电矩阵等结果进行交叉核对。

2. **MATLAB 和 Python 程序检查与调试**

	对程序运行流程、变量含义、数据读取方式、数组索引、数据维度、线性规划约束、跨日储能状态传递和时段划分口径进行辅助检查；根据报错信息或运行结果分析可能的路径、维度、单位和逻辑问题。参赛队员根据建议自行修改程序并重新运行确认。

3. **模型流程审阅**

	对问题二“预测—日前优化—实时调度—储能状态更新—滚动到下一天”的流程进行逻辑审阅，辅助检查预测数据与实际数据的使用时机、储能上下限、充放电效率、紧急购电条件及功率和能量的单位换算是否表述准确。

4. **图表制作指导**

	辅助指导 Origin 图表的坐标轴范围与刻度、图例位置、储能上下限虚线和指定日期参考线等设置。例如，在全年每日紧急购电量图中标注3月20日、6月21日、9月23日和12月21日四个日期。图表由参赛队员根据程序结果自行绘制、检查并导出。

5. **论文写作、排版和语言润色**

	在参赛队提供模型思路和计算结果的前提下，辅助组织章节结构、撰写部分段落草稿、检查公式与符号的一致性，并协助处理 LaTeX 模板使用、图片插入、编译错误、章节与图表编号及页数控制等问题，同时对中文学术表达进行润色。论文中的具体观点、公式、参数和结论均由参赛队员结合题目要求和最终程序结果确定。

## 三、主要提示方式和使用过程

使用过程均为“参赛队提供模型设定、输入数据和具体要求，人工智能工具给出建议或草稿，参赛队员判断取舍并进行人工核验”的循环。典型交互包括：

1. **结果核验**：输入问题二程序输出的年度汇总，要求按照题目要求核算计划购电量、计划购电费用、紧急购电量和费用，并说明报告期天数的确定方式；人工智能工具输出核对清单，参赛队员再与结果文件逐项比对。
2. **程序调试**：输入报错信息和相关代码片段，获取问题定位及修改建议；参赛队员修改后重新运行程序，并检查结果及约束条件是否满足。
3. **绘图指导**：输入全年每日紧急购电量图的绘制要求，获取 Origin 菜单操作步骤和参数设置；参赛队员按步骤完成绘图并导出图件。
4. **写作辅助**：输入模型说明文档和关键数值，获取章节结构及段落草稿；参赛队员逐句核对其中的数值和表述后再决定是否采用。

## 四、对人工智能输出的采纳、修改和核验

1. **直接采用**：绘图软件的部分操作步骤、LaTeX 排版方法、文字组织方式和语言表达建议。
2. **修改后采用**：人工智能工具提供的章节草稿和文字建议。草稿中的所有数值均与参赛队员实际运行的程序输出逐项核对；如有不一致，一律以程序输出为准。全部图表均由参赛队员按建议自行绘制并确认后使用。
3. **未采用**：人工智能工具提出的部分替代建模思路，例如以卡尔曼滤波替代本文的残差更新、以随机规划替代确定性调整模型等，因缺乏数据支撑或超出赛程未予采用。人工智能工具给出的示例代码仅作参考，实际求解程序由参赛队员自行编写、修改和运行。
4. **人工核验**：参赛队员对原始附件、Excel 文件、NPZ 文件、JSON 文件和程序输出之间的数据对应关系进行了确认，并检查了预测模型、目标函数、约束条件、实时调度规则、充放电效率、时间步长、功率和能量单位换算。程序结果通过功率平衡、储能上下限、能量守恒、跨日储能量连续性和费用分解一致性等检查；论文中的表格、图形、数值结果及关键结论均与最终程序输出一致，并由参赛队员独立复算确认。

语言润色类内容不改变建模过程和计算结果，不作为结果核验的依据。

## 五、责任说明

人工智能生成的建议、文字和代码仅作为辅助参考，不直接作为最终结论。本项目的模型设计、程序组织、结果分析和最终论文内容由参赛队员主导完成并负责。人工智能工具没有替代参赛队员独立思考，所有被采用的输出均经过人工审查、修改或核验，参赛队员对论文及支撑材料的全部内容负责。
