# 支撑文件目录

本目录用于说明本参赛队提交的支撑材料结构，便于查阅论文中的程序、结果和图表。

## 一、建议查阅顺序

1. **结果文件**：查看各问题的主要计算结果。
2. **所有图表**：查看论文中使用的图表及相关结果展示。
3. **源程序**：查看 MATLAB、Python 求解程序及运行所需附件。
4. **人工智能使用情况**：查看人工智能工具的使用范围、使用过程和人工核验情况。

## 三、各类材料说明

### 1. 结果文件

`结果文件/`保存各问题的主要计算结果，文件名中的编号与论文问题编号对应。问题四包含不同方案的结果文件，分别用于对应方案的结果分析和比较。

### 2. 所有图表

`所有图表/`按照问题一至问题四分类保存论文使用的图表，包括结果曲线、方案对比图、预测效果图、费用分析图和流程图等。图表文件主要为 PDF 矢量图，部分流程图为 PNG 图片。

### 3. 源程序

`源程序/`同时提供 MATLAB 和 Python 两类程序：

- `matlab/Q1/` 至 `matlab/Q4/`：各问题 MATLAB 程序及对应附件、测试文件；
- `python/Q1/` 至 `python/Q4/`：各问题 Python 求解程序；
- `python/附件/`：Python 程序运行所需的原始数据和附件文件；
- `README.pdf`：源程序目录及运行方式说明。

Python 程序主要文件如下：

| 问题 | 程序文件 |
|---|---|
| 问题一 | `solve_q1_two_cases.py` |
| 问题二 | `solve_q2.py`、`q2_experiments.py`、`q2_perfect_foresight.py` |
| 问题三 | `solve_q3.py`、`finalize_q3.py` |
| 问题四 | `solve_q4.py` |

### 4. 人工智能使用情况

`人工智能使用情况/AI_工具使用详情.pdf`说明本参赛队使用人工智能工具的名称、使用目的、具体环节、典型使用过程、输出采纳情况以及人工复核和责任说明。
